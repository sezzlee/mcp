The requested docs deployment is complete: Worker `sezzlee-docs`, version `ac361d9f-12ab-43f8-ae24-704f8c74b1cf`, deployment `771c86dc-9693-4985-ad83-b27fdbabb4d0`. Ten production URLs returned HTTPS 200 with expected updated content, including the [new chart/pivot recipe](https://docs.sezzlee.app/docs/excel-mcp/build-a-chart-and-pivot-report), [formatted report](https://docs.sezzlee.app/docs/excel-mcp/build-a-formatted-report) and [tool reference](https://docs.sezzlee.app/docs/excel-mcp/tools). New writing recipes identify the current source-build requirement until package publication.

LibreOffice can drop the deterministic report's `stopIfTrue` flag on export. The original flag and relative/effective rules remain independently checked. Desktop Excel interaction and arbitrary advanced-feature combinations are not claimed. Macro execution, encrypted/signed editing and unsupported protection remain refused. The five generic model/OCR docs skips are not Excel acceptance skips.

Licensed corpus files, private endpoints, full model traces, generated workbooks and local logs remain outside this public repository. The evidence-only closing commit uses `[skip ci]`; it changes no validated runtime or tests. No PR merge, npm publication or private product rollout was performed.
